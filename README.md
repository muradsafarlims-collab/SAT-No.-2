# No. 2 Daily

A static website for daily SAT Reading & Writing practice, styled like a digital SAT exam room.

- Upload a PDF of questions with answers. It is read in your browser and never uploaded anywhere.
- Each day gives you 10 questions: easy first (with a couple of medium ones mixed in), then medium, then hard. If the PDF has no difficulty labels, questions come in PDF order.
- Exam screen: passage and question side by side, timer with Hide, Mark for Review, answer crossing-out, question map, review page.
- After you submit: score, bubble answer sheet, skill breakdown, and every answer with its explanation.
- Progress is saved in the browser (localStorage). No account, no server.

Unofficial practice tool. Not affiliated with or endorsed by the College Board.

## Run locally

Open `index.html` in a browser (internet is needed for the PDF reader and fonts).

## PDF tips

Text PDFs work. Scanned pages do not. Answer choices must start with A., B., C., D. Answers can sit under each question ("Correct Answer: B", "Rationale") or in an answer key at the end ("1. B"). Charts and images are not copied.
